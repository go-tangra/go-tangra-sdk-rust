# notes join bundle

Generated by the gateway (Gateway operations › Modules › notes › Add).

    docker compose up -d

`private/` holds the single-use enrolment token; `config.yaml` holds the
event-bus password you gave. Keep them on this host only. After the first
start the module renews its identity itself (`/state/svid.json`).

notes joins the core's event bus (Valkey, TLS) as user `notes`: the core's
Valkey must accept that user from this host. On the core, auth's policy must
allow `spiffe://<trust domain>/svc/notes` to call
`auth.v1.Authorization/Check`.
