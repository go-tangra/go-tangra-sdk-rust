You need the `notes:write` permission (the built-in *member* role and the
*Notes editor* role have it).

## 1. Write a note

1. Open **Notes** in the navigation.
2. Choose **New note**.
3. Enter a title, and optionally some text.
4. Choose **Save**. The note appears at the top of the list.

## 2. Find it again

The list shows the newest notes first. Choose a column header to sort by
title or date, and type in **Search** to keep only notes whose title contains
the text.

Colleagues who have the list open see new notes appear without reloading the
page.
